# 펫아모스 병원 마케팅 진단 — 5축 기준·방법론

> 이 문서는 **마케팅 문구가 아니라 실제 엔진 코드(`engine/scoring.py`·`policy.py`·`insights.py`·`ai_draft.py`)가 채점하는 방식**을 정리한 것입니다. 숫자·가중치·등급 기준은 코드와 1:1로 일치합니다.

---

## 0. 종합 점수는 어떻게 나오나

- **종합 점수 = 측정된 진단 축의 단순 평균(각 축 동일 가중), 0~100.**
- 종합 점수에 들어가는 축은 **4개**: **① 상권 · ② 경쟁 · ③ 마케팅 · ④ 리뷰**.
- **⑤ 진료 강점**은 점수에 넣지 않습니다 — 앞 4축을 종합한 **서술형 제언**(리포트 05)이라 별도 취급.
- 측정 안 된 축은 평균에서 빠지고, **커버리지(%) = 측정된 축 / 4** 로 표기(데이터가 없으면 정직하게 낮게).

**종합 등급 (`policy.AXIS_GRADES`)**

| 점수 | 등급 |
|---|---|
| 80 이상 | **A** |
| 65 이상 | **B** |
| 50 이상 | **C** |
| 그 미만 | **D** |

> 참고 — 랜딩의 **오각형(펜타곤)** 은 상권·경쟁·온라인노출·리뷰·진료강점 **5축**을 보여주는 *시각화*이고, **엔진의 종합 점수는 4축 평균**입니다(진료강점은 서술 종합). 두 개를 혼동하지 않도록 주의.

각 축은 **여러 지표를 가중 평균**해 0~100(`axis_score100`)으로 냅니다. 측정 안 된 지표는 제외하고 남은 지표로 계산(coverage 반영).

## ① 상권 (`analyze_trade_area`) — 시장 크기와 경쟁 밀도

**질문**: "이 자리, 반려 시장이 크고 병원 대비 여유가 있나?"

| 지표 | 가중치 | 무엇을 보나 | 채점 밴드 |
|---|---|---|---|
| **시장규모·포화도** | **30%** | **포화도 = 반려가구 ÷ 상권 내 병원 수** | ≥2000→90, ≥1500→80, ≥1100→66, ≥800→52, ≥500→42, 그 외 33 |
| 유동인구·상권활력 | 20% | 일일 평균 유동인구 | ≥25만→90 … ≥2만→45 |
| 입지·주차·역세권 | 20% | 가까운 역·주차·아파트 밀집 여부 | 플래그 조합 |
| 소득·소비력 | 15% | 월평균 추정매출(상권) | ≥6000만→90 … ≥2500만→45 |
| 상권유형 | 15% | 주거/상업/혼합 | 유형별 |

**반려가구 추정(정석, `policy.PET_OWNERSHIP_RATE`)**
- 가구수(통계청 SGIS) 있으면 → **반려가구 = 가구수 × 0.28**
- 없으면 → 등록 반려동물수 × 1.5(`PET_HH_FROM_REG`)로 역산

**포화도 등급(`policy.SATURATION_GRADES`)** — 반려가구가 병원 1곳당 몇인지

| 포화도(반려가구/병원) | 등급 |
|---|---|
| 1500 이상 | **A · 여유(블루오션)** |
| 1100 이상 | **B · 양호** |
| 800 이상 | **C · 보통** |
| 그 미만 | **D · 포화(레드오션)** |

**데이터 소스 / 자동화**: 포화도(가구수=SGIS, 병원수=카카오 반경검색, 등록수=참조CSV)는 **주소만으로 자동**. 유동인구·매출·소득·상권유형은 소상공인 상권정보(간단분석 PDF 또는 공공 API) 필요 — *자동화 진행 중*.

## ② 경쟁 (`analyze_competition`) — 주변 동급 병원 대비 위치

**질문**: "주변 같은 급(2차) 병원과 비교해 우리는 어디쯤인가? 남들이 안 하는 빈자리는?"

먼저 반경 내 병원을 **동급 경쟁(rivals)** 과 **의뢰처(referrals, 다른 tier·주로 1차)** 로 나눕니다(2차 판별 = `policy.TIER2_SIGNALS`: 메디컬센터·의료원·24시·응급·야간·2차·레퍼럴·전문동물 등).

| 지표 | 가중치 | 무엇을 보나 |
|---|---|---|
| **경쟁 포지션(밀도)** | **30%** | 반경 내 동급 경쟁 병원을 **거리 가중**으로 집계 → 적을수록 높은 점수(여유). 2차는 주변 1차 **의뢰처 풀 보너스**(최대 +20). 범위 10~100 |
| **상대 포지션(리뷰·평점)** | **30%** | 우리 리뷰 수를 경쟁사들과 비교한 순위(상위/중위/하위권) |
| **빈자리(희소 특화)** | **25%** | 경쟁사들이 **안 하는 특화**(치과·안과·심장·영상 CT·MRI·초음파·응급 등) = 우리 기회 |
| 경쟁사 프로필(과목·24시) | 15% | 경쟁사 중 강한 곳(2차 신호·특화 보유) 비율 |

**특화 키워드(`policy.SPECIALTY_KEYWORDS`)**: 치과 · 안과 · 심장·순환기 · 영상(CT·MRI) · 초음파 · 혈액검사 · 24시·응급 · 정형·재활 · 신경 · 종양

**경쟁사 마케팅 현황(`analyze_competition_marketing`)** — 별도 산출
- 경쟁사 각 채널을 **운영 / 없음 / 미확인(3-state)** 으로 집계
- **상권 온라인 성숙도** = (확인된 채널 중 운영 비율) → 높음 ≥60 / 보통 ≥30 / 낮음
- **운영 강도 랭킹**(경쟁사 + 우리), **빈 채널**(다들 안 하는 채널 = 기회)

**데이터 소스 / 자동화**: 경쟁 병원 목록·거리·리뷰수는 **카카오 반경검색으로 자동**. 경쟁사 특화·채널 운영 현황은 각 경쟁사에 발견+캡처 파이프라인 재적용 예정 — *자동화 진행 예정*.

## ③ 마케팅 / 온라인 노출 (`marketing_axis100`) — 채널별 완성도

**질문**: "우리 온라인 채널들이 실제로 얼마나 잘 돼 있나?"

- **마케팅 축 점수 = 측정된 채널 점수(0~100)의 평균.**
- 각 채널은 **캡처 화면을 Claude 비전이 판독**(`draft_channel_from_images`)해서 채점 — 화면에 실제로 보이는 값만 근거, 없는 값은 '확인 필요'.

**채널별 평가 관점(`ai_draft.CHANNEL_CRITERIA`)**

| 채널 | 무엇을 보나 |
|---|---|
| 홈페이지 | 디자인·정보구조·전화/예약 전환 동선·모바일·검색 노출·구조화 정보 |
| 네이버 블로그 | 발행 주기·정보성·검색 노출·이웃 수·전문 콘텐츠 |
| 인스타그램 | 팔로워·게시 빈도·릴스/숏폼·브랜딩·프로필 완성도 |
| 네이버 플레이스 | 별점·리뷰 수·정보 정확성·소식·사진 수 |
| 카카오톡 채널 | 친구 수·상담 창구·소식·쿠폰·응대 |
| 카카오맵 | 정보 정확성(상호·주소·전화)·후기 on/off·사진 |
| T맵 | 이름·주소·전화·핀 정합성 |
| AEO·GEO(AI 검색 노출) | 구조화 정보·자주 묻는 질문·엔티티 일관성·생성엔진 노출 |

**각 채널 산출물**: 종합 점수(0~100) + 항목별 세부 수준(좋음/보통/약함) + 리뷰수·별점 + 한 줄 평 + 유의점.
**종합 패스(`synthesize_marketing`)**: 채널을 가로지르는 **공통 강점 3개 · 공통 과제 5개**로 재종합.

**데이터 소스 / 자동화**: 캡처(홈피·인스타·네이버는 **로그인 세션 자동 캡처**) + 비전 분석까지 **자동 구현·검증됨**. 채널 URL 자동 발견은 *진행 중*(영문 브랜드 병원은 자동, 한글 이름·플레이스는 보완 필요).

## ④ 리뷰·평판 (`review_axis100`) — 검증된 평판 자산

**질문**: "실제 보호자 평판이 얼마나 좋고 두터운가?"

- **리뷰 축 점수 = 리뷰 수 가중 긍정률** = Σ(채널 긍정% × 리뷰수) ÷ Σ(리뷰수).
  → 리뷰가 많은 채널의 긍정률이 더 크게 반영됨.
- 채널별로 **별점 · 리뷰 수 · 감정(긍정/중립/부정) · 키워드**를 봄(플레이스·블로그·구글).
- **리뷰 수 기준(중요)**: 네이버 플레이스 **프로필 상단 총계(방문자 + 블로그 합산)** 를 기준으로 하고, **경쟁사도 같은 기준**으로 셈.
- **종합 패스(`synthesize_reviews`)**: 공통 칭찬 · 반복되는 불만 · 운영 힌트로 종합.

**데이터 소스 / 자동화**: 구글은 Places API(구조화), 네이버는 플레이스/블로그 캡처+비전 — *플레이스 URL 확보가 관건, 자동화 예정*.

## ⑤ 진료 강점 (`insights.derive_strengths`) — 종합 제언 (점수 제외)

**질문**: "그래서 이 병원의 무기는 무엇인가?" — 앞 4축에서 **강점만** 뽑아 종합(리포트 05). **종합 점수에는 넣지 않음.**

5개 강점 축(데이터 있는 축만 자동 삽입):

| 강점 축 | 근거(어느 분석에서) |
|---|---|
| **진료 역량·전문성** | 병원 특화(의료진·장비·특화·시설) — 마케팅 분석에서 계열별(외과·영상·응급·내과 등)로 자동 추출 |
| **평판·리뷰** | ④ 리뷰 결과(리뷰 N개·긍정 %) |
| **경쟁 포지션** | ② 경쟁 결과(경쟁 여유·의뢰처) |
| **입지·상권** | ① 상권 결과(등급·접근성) |
| **온라인·브랜드 자산** | ③ 마케팅 결과(고득점 채널) |

# 병원 마케팅 리포트 생성기 (V2)

동물병원 하나의 입력 JSON 1개로 **6개 리포트를 정해진 순서로** 자동 생성합니다.

```
01 상권분석 → 02 경쟁분석 → 03 마케팅 → 04 리뷰분석 → 05 강점 → 06 12개월 마케팅 계획
```

앞의 4종(상권·경쟁·마케팅·리뷰)은 **진단**, 05는 그 강점만 뽑은 **종합**, 06은 강점을 실행으로 옮기는 **계획** — 순서대로 읽으면 진단 → 강점 → 실행이 한 흐름으로 이어집니다.

01~06은 **외부 시장·온라인** 관점입니다. 진료 백업 파일(EMR)을 함께 넣으면 **내부 데이터** 관점의 **07 진료데이터분석**(재진율·휴면·객단가·주력질환 + 12개월 로드맵)이 추가로 생성됩니다(선택). → 아래 **10) 진료데이터(EMR) 분석**.

## 사용법

### 1) 리포트 생성
```bash
cd ~/Desktop/병원마케팅V2
python3 -m engine.generate inputs/부평스카이동물의료센터.json
```
→ `outputs/<병원명>/` 에 `01`~`06` HTML + `index.html` 생성.

### 2) 브라우저에서 보기
```bash
python3 -m http.server 8531 --directory outputs
# 브라우저: http://localhost:8531/<병원명>/index.html
```
또는 `outputs/<병원명>/index.html` 파일을 더블클릭. (인쇄 → PDF 저장 가능)

### 3) 새 병원 추가
`inputs/<병원명>.json` 을 아래 스키마로 작성하고 2)를 다시 실행하면 됩니다.

### 4) 웹 UI (권장)
```bash
python3 -m engine.webapp        # → http://localhost:8600
```
- **+ 새 병원 진단**: 폼에 직접 입력 → 6리포트 생성
- **✏️ 수정·보완**: 홈의 병원 카드에서 클릭하면 기존 입력이 채워진 폼이 열립니다. **빠진 부분만 채워** 저장(`/update`)하면, 건드리지 않은 값과 **진료데이터(EMR)·기존 리포트는 유지**한 채 다시 생성됩니다. (처음부터 다시 입력할 필요 없음)
- **✨ AI 초안으로 시작**: 원재료(링크·캡처요약·리뷰 원문)를 넣으면 Claude가 ③마케팅·④리뷰 초안(JSON)을 만들어 검수 화면에 채워줌 → 편집 후 생성

### 5) AI 초안층 켜기 (선택)
AI 초안은 코어 엔진과 분리된 **선택 애드온**입니다. 없어도 폼으로 직접 입력하면 6리포트가 나옵니다.
```bash
pip install anthropic
export ANTHROPIC_API_KEY=sk-ant-...
python3 -m engine.webapp        # 재시작하면 AI 초안 활성화
```
- 모델 `claude-opus-4-8`, structured output(json_schema)로 스키마 강제 → 파싱 실패 없음(PRD §8).
- 환각 방지: "원재료에 없는 수치는 지어내지 말 것, 불명은 확인 필요"를 시스템 프롬프트에 명시.
- **초안일 뿐**입니다 — 검수 화면에서 점수·문구를 수정한 뒤 생성하세요(사람 검수가 최종 안전장치).
- 키가 없으면 웹앱은 '예시(목업) 초안'으로 흐름만 시연합니다(리포트에 '예시·AI 미연결' 표기).
- 상태 확인: `python3 -m engine.ai_draft`

### 6) §9 링크 자동수집 (AI 초안과 함께)
**✨ AI 초안으로 시작** 화면의 **③-A 링크 자동수집**에 URL을 넣으면, `collectors.py`가 공개 페이지를 단발 조회해 **title·meta·OG·H1·전화(tel)·이미지 alt·구조화데이터(JSON-LD)·SPA 여부**를 추출하고, 그 요약을 AI 초안의 원재료로 넣습니다.
- **자동수집**: 홈페이지·T맵 / **공개 메타만**: 카카오맵·인스타(약관상 상세 자동수집 안 함)
- **캡처 업로드(비전)**: 네이버 블로그·플레이스·카카오톡·AEO는 자동 수집 금지(약관) → ③-B에 **캡처 이미지를 업로드**하면 Claude 비전이 별점·리뷰수·친구수 등을 판독(원문에 없는 값은 지어내지 않고 '확인 필요'). ④ 리뷰도 캡처 업로드 지원.
- 안전장치: http/https만, 사설·로컬 IP 차단(SSRF 가드), 타임아웃·크기 제한, 단일 페이지만 조회(크롤 없음). 업로드는 stdlib multipart 파싱(바이너리 무결성 보장).
- 테스트: `python3 -m engine.collectors <url>`

### 7) 상권 자동화 — 간단분석 PDF만 넣으면 (§상권)
소상공인시장진흥공단 **'간단분석 리포트' PDF**를 ① 상권 섹션에 업로드하면 `ingest.py`가 자동 추출:
- **지역·월평균매출·일유동인구·동물병원 업소수**(시군구, 퍼센트 역산) + 참조 CSV에서 **등록 반려동물수** 조회
- → 시장 포화도·등급·상권 축 점수 자동 산출. 가구수 없이 **등록수 기반으로 반려가구 추정**(policy.PET_HH_FROM_REG, 조정 가능).
- 세팅(1회): `reference/pet_registration_sigungu.csv`(전국 시군구 등록수, 농림부). 최신본으로 교체 가능.
- **통계청 SGIS 연동(선택)**: `🔑 키 설정`에 SGIS 서비스ID·보안Key를 넣으면, 상권분석 시 **시군구 가구수를 자동 조회**(`sgis.py`)해 반려가구 = 가구수×0.28 **정석 계산**. 없으면 등록수×1.5 추정으로 대체. 키 발급: sgis.kostat.go.kr/developer. 테스트: `python3 -m engine.sgis "인천광역시" "남동구"`
- 없는 값(역세권·상권유형)만 폼에 보완 입력. 테스트: `python3 -m engine.ingest <간단분석.pdf>`

### 8) 경쟁 자동수집 — 주소만 넣으면 (§경쟁 · 카카오)
병원 **주소 + tier 반경**(1차 1km/2차 3km)으로 `kakao.py`가 반경 내 동물병원을 자동 검색합니다. 두 가지 방식:

- **방법 A(권장) — 먼저 수집 → 검수 → 확정**: ② 경쟁의 **🗺️ 카카오로 먼저 수집 → 결과 확인** 버튼을 누르면 수집 결과가 **같은 입력 폼에 채워져** 되돌아옵니다(`/collect_competition`). 목록에서 **진짜 경쟁병원이 맞는지 확인해 아닌 곳은 지우고**, 자동 프리필된 '경쟁사 마케팅 현황'(동급 경쟁 상위 15곳)에 채널 운영 여부를 채운 뒤 생성합니다. 사용자가 이미 입력한 값은 유지되고, 재수집(방법 B)은 자동으로 꺼집니다. **파일 첨부(PDF·캡처·EMR)는 수집 후에** 하세요(폼 왕복 시 파일은 유지되지 않음).
- **방법 B — 생성 시 자동수집**: '생성할 때 자동수집' 체크 시 결과 확인 없이 /generate에서 바로 수집·분석.
- 공통: 주소 지오코딩 → "동물병원" 키워드 검색(거리순, 최대 45곳) → 1/2차 자동분류·거리가중·co_density·빈자리·주변 병원 지형표 산출. **자동**: 병원 수·거리·경쟁/의뢰처 분류. **반자동**: 리뷰 상대포지션(경쟁사 리뷰 필요 → 결측).
- 카카오 키: **🔑 API 키 설정** 화면의 카카오 섹션에 REST API 키 입력(발급: developers.kakao.com). 저장 시 검증·영구보관.
- 테스트: `python3 -m engine.kakao "<주소>" [반경m]`

### 9) API 키 저장(재시작해도 유지)
**🔑 API 키 설정** 화면에서 **☑ 이 맥에 저장**을 체크하면 `~/.config/petamos/api_key`(0600)에 보관되어, 웹앱을 재시작해도 자동 로드됩니다. 삭제는 같은 화면의 "저장된 키 삭제".

### 10-B) 경쟁사 마케팅 분석 — 02 경쟁분석 안에 (선택)
② 경쟁 입력의 **🆚 경쟁사 마케팅 현황**에 경쟁사별 채널 운영 여부를 넣으면, 02 리포트에 세 섹션이 추가됩니다(`scoring.analyze_competition_marketing`).

- **입력 방식**: 핵심 경쟁 **3곳만** — 병원명 + 채널별 **드롭다운(운영 / 없음 / 미확인)** + 리뷰수(선택). 카카오 '먼저 수집→확인'을 쓰면 **가장 가까운 경쟁 3곳 이름이 자동 프리필**되어, 각 채널만 골라주면 됩니다. (4곳 이상은 '고급' 접기에서 `병원명, 홈페이지, 블로그, 인스타[, 리뷰수]` 텍스트로 직접 입력 — 별칭 o·x·? 허용.)
- **핵심 원칙 — "안 함"은 결측이 아니라 기회**: 검색·지도에서 확인해봐도 채널이 없으면 **‘없음(확인)’**, 아직 안 봤으면 **비워둠(미확인)**. ‘없음’은 **기회 신호**로, ‘미확인’은 **성숙도 계산에서 제외**됩니다.
- **① 특화 포지셔닝 맵**: 카카오 수집 경쟁사 × 특화(치과·안과·심장·영상 등) 매트릭스 + **빈자리(경쟁사가 안 내세우는 진료)**. rival_marketing 없어도 **자동 동작**.
- **② 채널 진단 + 상권 온라인 성숙도**: 채널별 운영/없음/미확인 집계, **빈 채널** 판정, **상권 온라인 성숙도**(확인된 것 중 운영 비율 — 낮을수록 기회), 운영 강도 랭킹(본 병원 포함).
- **③ tier별 전략**: **1차 = 저비용 선점**(무주공산이면 “기본기만 갖춰도 검색 선점”), **2차 = 전문성 차별화**(“양이 아니라 케이스 깊이로”). `clinic.tier`로 제언이 갈립니다.

### 10) 진료데이터(EMR) 분석 — 07 리포트 (선택 · 내부 데이터축)
새 병원 폼 **⑤ 진료데이터(EMR)** 칸에 진료 백업 파일(**.csv / .xlsx**)을 올리면 `emr.py`가 처리해 **07 진료데이터분석** 리포트를 추가 생성합니다. Petamos(`~/petamos`)의 방법론을 pandas 없이 stdlib(+openpyxl)로 이식한 것으로, 파라미터·공식이 1:1 동일합니다.

- **개인정보 우선(안전장치)**: 업로드 즉시 **보호자명·전화·주소는 삭제**, 환자는 세션 랜덤 솔트 + SHA-256 **가명 ID**(`P…`)로만 구분(재식별 불가). 세션 솔트는 처리 후 폐기. **입력 JSON·리포트에는 원본 개인정보를 저장하지 않고 집계 지표만** 담습니다.
- **자동 컬럼 매핑**: EMR마다 다른 컬럼명을 표준 필드로 자동 인식(정확→부분포함). 최소 필수 = **진료일 + 금액**(수납액·내원일 등 이형도 인식).
- **지표**: 재진율(재방문 2회+), 휴면(6개월 미방문), 객단가(ARPU 방문/환자당), 고관여 진료 후보(진단별 평균 상위·80분위), 질환 유입 믹스 Top 8.
- **12개월 로드맵**: 규칙 기반(키 불필요). 약점→과제 가중치 매칭(재진율<40%·휴면·고관여·주력질환) → 분기 테마(1Q정비→2Q리텐션→3Q신규→4Q객단가·평판)에 라운드로빈 배분.
- **xlsx 판독**: `openpyxl` 필요(설치돼 있으면 자동). 없으면 폼에서 **CSV로 올리라고 안내**.
- CLI 테스트: `python3 -c "from engine import emr; print(emr.run(open('진료백업.csv','rb').read(),'진료백업.csv','병원명')['analysis'])"`

- 실행 우선순위(바로/중기/장기)는 `effort/impact/cost`로 `score_action`이 자동 계산합니다(효과×3 − 노력 − 비용).
